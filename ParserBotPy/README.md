# 🤖 Парсер цен для Telegram-бота

Автоматический парсер цен конкурентов с интеграцией в Webasyst и управлением через Telegram-бота.

## 📋 Описание

Этот проект представляет собой комплексное решение для автоматического мониторинга цен конкурентов и обновления цен в вашем магазине Webasyst. Основные возможности:

- 🔍 **Парсинг цен** с сайтов конкурентов
- 🤖 **Telegram-бот** для управления и уведомлений
- 🔄 **Автоматическое обновление** цен в Webasyst
- ⏰ **Планировщик** для регулярного парсинга
- 📊 **Статистика** и отчеты
- 🛡️ **Защита от блокировки** (User-Agent, задержки)

## 🏗️ Архитектура

```
ParserBotPy/
├── config/          # Конфигурация
├── parsers/         # Парсеры сайтов
├── bot/            # Telegram-бот

├── main.py         # Главный файл

```

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd ParserBotPy
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Скопируйте файл `config/env.example` в `.env` и заполните необходимые параметры:

```bash
cp config/env.example .env
```

Отредактируйте файл `.env`:

```env
# Telegram Bot Configuration
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TELEGRAM_ADMIN_ID=your_telegram_user_id_here

# Webasyst API Configuration
WEBASYST_API_URL=https://your-shop.webasyst.net/api/
WEBASYST_API_TOKEN=your_webasyst_api_token_here
WEBASYST_SHOP_ID=your_shop_id_here

# Parsing Configuration
PARSING_INTERVAL_MINUTES=30
REQUEST_DELAY_SECONDS=2.0
MAX_RETRIES=3

# Logging Configuration
LOG_LEVEL=INFO
LOG_FILE=logs/parser_bot.log

# Price Configuration
MIN_PRICE_MARGIN=0.05
MAX_PRICE_DROP=0.20
```

## ⚙️ Настройка

### 1. Создание Telegram-бота

1. Найдите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `.env`

### 2. Получение ID пользователя

1. Найдите @userinfobot в Telegram
2. Отправьте любое сообщение
3. Скопируйте ваш ID в `.env`

### 3. Настройка Webasyst API

1. Войдите в панель управления Webasyst
2. Перейдите в раздел "Настройки" → "API"
3. Создайте новый API-ключ
4. Скопируйте токен и URL в `.env`

### 4. Настройка сайтов для парсинга

Отредактируйте файл `config/settings.py` и добавьте сайты для парсинга:

```python
TARGET_SITES = [
    {
        "name": "competitor_site_1",
        "url": "https://competitor1.com",
        "price_selector": ".price",
        "title_selector": ".product-title",
        "enabled": True
    },
    {
        "name": "competitor_site_2", 
        "url": "https://competitor2.com",
        "price_selector": "[data-price]",
        "title_selector": "h1",
        "enabled": True
    }
]
```

## 📱 Команды бота

- `/start` - Запуск бота и главное меню
- `/status` - Показать текущий статус системы
- `/parse_now` - Запустить парсинг цен вручную
- `/settings` - Настройки парсера и API
- `/stats` - Статистика работы
- `/help` - Справка по командам

## 🔧 Настройка парсинга

### CSS-селекторы

Для каждого сайта нужно указать CSS-селекторы для извлечения цен и названий товаров:

```python
{
    "name": "site_name",
    "url": "https://site.com",
    "price_selector": ".price",           # Селектор для цены
    "title_selector": ".product-title",   # Селектор для названия
    "enabled": True
}
```

### Примеры селекторов

- **Цена**: `.price`, `[data-price]`, `.product-price`, `#price`
- **Название**: `h1`, `.product-title`, `.item-name`, `[data-title]`

## 🔧 Расширение функционала

### Добавление нового парсера

1. Создайте новый класс в `parsers/`
2. Наследуйтесь от `BaseParser`
3. Переопределите методы при необходимости
4. Добавьте конфигурацию в `settings.py`

### Интеграция с другими магазинами

1. Создайте новый класс API в `parsers/`
2. Реализуйте методы для работы с API
3. Обновите `ParserManager`

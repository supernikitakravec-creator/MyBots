# 🎁 TgGIFT Star Bot

Telegram бот для мониторинга и автоматической покупки подарков с системой подписок и внутренней валютой.

## 🚀 Возможности

### 📊 Система подписок
- **Базовая подписка** (699⭐) - мониторинг новых подарков
- **VIP подписка** (1299⭐) - автопокупка + мониторинг

### 💰 Система баланса
- Пополнение баланса звездами (комиссия 10%)
- Автоматические покупки для VIP пользователей
- Система очереди покупок

### 🤖 Автоматизация
- Мониторинг новых подарков в Telegram
- Автоматическая покупка через управляемый аккаунт
- Уведомления о новых подарках

## 📋 Требования

- Python 3.8+
- Telegram Bot Token
- Telegram Client API (для управляемого аккаунта)

## 🛠️ Установка

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd TgGIFT
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации

Скопируйте `env_example.txt` в `.env` и заполните настройки:

```env
# Telegram Bot Token (получите у @BotFather)
BOT_TOKEN=your_telegram_bot_token_here

# Telegram Client API (для управляемого аккаунта)
API_ID=your_api_id_here
API_HASH=your_api_hash_here
PHONE_NUMBER=+7xxxxxxxxxx

# Настройки базы данных
DATABASE_PATH=gift_bot.db

# Интервалы мониторинга (в секундах)
MONITORING_INTERVAL=60
GIFT_CHECK_INTERVAL=30
```

### 4. Получение токенов

#### Telegram Bot Token
1. Найдите @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен

#### Telegram Client API
1. Перейдите на https://my.telegram.org/apps
2. Войдите в свой аккаунт
3. Создайте новое приложение
4. Скопируйте API_ID и API_HASH

```bash
python check_config.py
```


```bash
python main_bot.py
```

## 📖 Использование

### Команды бота
- `/start` - Главное меню
- `/subscription` - Управление подписками
- `/balance` - Баланс и пополнение
- `/queue` - Очередь покупок
- `/gifts` - Просмотр подарков
- `/topup` - Пополнение баланса
- `/help` - Справка

### Покупка подписки
1. Отправьте подарок звездами боту
2. Выберите тип подписки
3. Бот автоматически активирует подписку

### Пополнение баланса (VIP)
1. Убедитесь, что у вас VIP подписка
2. Отправьте подарок звездами боту
3. Укажите желаемую сумму (комиссия 10%)

### Очередь покупок
1. Купите VIP подписку
2. Встаньте в очередь через `/queue`
3. Пополните баланс
4. Бот автоматически покупает подарки по очереди

## 🚨 Устранение проблем

### Бот не отвечает
1. Проверьте токен бота
2. Убедитесь, что бот запущен
3. Проверьте логи: `tail -f bot.log`

### Ошибки подключения
1. Проверьте интернет-соединение
2. Убедитесь, что API_ID и API_HASH правильные
3. Проверьте номер телефона

### Проблемы с базой данных
1. Удалите файл базы данных
2. Запустите `python init_database.py`
3. Перезапустите бота

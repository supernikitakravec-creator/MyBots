=============================================================================
                    УПРАВЛЕНИЕ TGGIFT BOT В ПРОДАКШЕНЕ
=============================================================================

📍 РАСПОЛОЖЕНИЕ ПРОЕКТА: /opt/tggift

=============================================================================
                        ОСНОВНЫЕ КОМАНДЫ
=============================================================================

🔍 ПРОВЕРКА СТАТУСА:
cd /opt/tggift && docker-compose ps

📊 ПРОСМОТР ЛОГОВ:
cd /opt/tggift && docker-compose logs -f tggift-bot
cd /opt/tggift && docker-compose logs --tail=50 tggift-bot
cd /opt/tggift && docker-compose logs postgres

🔄 УПРАВЛЕНИЕ БОТОМ:
cd /opt/tggift && docker-compose stop tggift-bot      # Остановить
cd /opt/tggift && docker-compose start tggift-bot     # Запустить
cd /opt/tggift && docker-compose restart tggift-bot   # Перезапустить
cd /opt/tggift && docker-compose up -d                # Запустить все сервисы

🛑 ПОЛНАЯ ОСТАНОВКА:
cd /opt/tggift && docker-compose down

🚀 ПОЛНЫЙ ЗАПУСК:
cd /opt/tggift && docker-compose up -d

=============================================================================
                        КРИТИЧЕСКИЕ СИТУАЦИИ
=============================================================================

🚨 БОТ НЕ ОТВЕЧАЕТ НА КОМАНДЫ:
1. Проверить статус:
   cd /opt/tggift && docker-compose ps
   
2. Посмотреть логи:
   cd /opt/tggift && docker-compose logs --tail=30 tggift-bot
   
3. Перезапустить:
   cd /opt/tggift && docker-compose restart tggift-bot

🚨 TELEGRAM API КОНФЛИКТ (Conflict: terminated by other getUpdates):
1. Очистить webhook:
   cd /opt/tggift && docker-compose run --rm tggift-bot python clear_webhook.py
   
2. Перезапустить бота:
   cd /opt/tggift && docker-compose restart tggift-bot

🚨 ОШИБКИ ПОДКЛЮЧЕНИЯ К БАЗЕ ДАННЫХ:
1. Проверить PostgreSQL:
   cd /opt/tggift && docker-compose logs postgres
   
2. Проверить подключение:
   cd /opt/tggift && docker-compose exec postgres psql -U tggift -d tggift -c "SELECT 1;"
   
3. Перезапустить базу:
   cd /opt/tggift && docker-compose restart postgres
   
4. Если не помогает - пересоздать:
   cd /opt/tggift && docker-compose down
   cd /opt/tggift && docker volume rm tggift_postgres_data
   cd /opt/tggift && docker-compose up -d

🚨 КОНТЕЙНЕР ПОСТОЯННО ПЕРЕЗАПУСКАЕТСЯ:
1. Посмотреть логи ошибок:
   cd /opt/tggift && docker-compose logs --tail=100 tggift-bot | grep ERROR
   
2. Проверить ресурсы сервера:
   df -h        # Место на диске
   free -h      # Память
   top          # Процессы
   
3. Пересобрать контейнер:
   cd /opt/tggift && docker-compose down
   cd /opt/tggift && docker-compose build --no-cache tggift-bot
   cd /opt/tggift && docker-compose up -d

🚨 НЕХВАТКА МЕСТА НА ДИСКЕ:
1. Очистить Docker:
   docker system prune -f
   docker image prune -f
   docker volume prune -f
   
2. Очистить логи:
   cd /opt/tggift && rm -rf logs/*
   
3. Очистить старые бэкапы:
   rm -rf /tmp/tggift_backup

                        ОБНОВЛЕНИЕ И БЭКАПЫ
=============================================================================

💾 СОЗДАНИЕ БЭКАПА БАЗЫ ДАННЫХ:
cd /opt/tggift && docker-compose exec postgres pg_dump -U tggift tggift > backup_$(date +%Y%m%d_%H%M%S).sql

💾 ВОССТАНОВЛЕНИЕ ИЗ БЭКАПА:
cd /opt/tggift && docker-compose exec -T postgres psql -U tggift -d tggift < backup_file.sql

💾 БЭКАП КОНФИГУРАЦИИ:
cd /opt && tar -czf tggift_config_backup_$(date +%Y%m%d_%H%M%S).tar.gz tggift/.env tggift/docker-compose.yml

🔄 ОБНОВЛЕНИЕ БОТА:
1. Создать бэкап:
   cd /opt && cp -r tggift tggift_backup_$(date +%Y%m%d_%H%M%S)
   
2. Остановить бота:
   cd /opt/tggift && docker-compose down
   
3. Обновить файлы (скопировать новые)
   
4. Пересобрать и запустить:
   cd /opt/tggift && docker-compose build --no-cache
   cd /opt/tggift && docker-compose up -d

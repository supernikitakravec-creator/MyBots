# 🎁 TgGIFT Bot 2.0 - НОВАЯ СИСТЕМА ГОТОВА!

## 🚀 **АРХИТЕКТУРА СИСТЕМЫ**

### 📋 **Упрощенная схема работы:**
```
👤 Пользователь покупает подписку (ЮКасса/TON)
    ↓
📊 Депозитные аккаунты мониторят новые подарки
    ↓
🎁 Пользователь покупает баллы (только VIP)
    ↓
💰 Баллы зачисляются (1₽ = 1 балл + бонусы)
    ↓
⚙️ VIP настраивает автопокупку в профиле
    ↓
🔍 Депозитные аккаунты находят подходящие подарки
    ↓
💸 Списываются баллы (резервирование → подтверждение)
    ↓
📦 Депозитный аккаунт покупает и отправляет подарок
    ↓
✅ Уведомление пользователю о доставке
```

## 🏗️ **КОМПОНЕНТЫ СИСТЕМЫ**

### 🏦 **Депозитные Аккаунты** (ОСНОВА СИСТЕМЫ)
- **Мониторинг подарков** через Telegram API
- **Покупка подарков** за Stars от имени пользователей  
- **Балансировка нагрузки** между аккаунтами
- **Статистика и лимиты** покупок

### 💳 **Платежная Система**
- **ЮКасса** - прием рублевых платежей
- **TON** - прием криптоплатежей
- **Webhook обработка** платежей
- **Автоматическое начисление** баллов/подписок

### 💎 **Система Баллов**
- **1₽ = 1 балл** базовый курс
- **Прогрессивные бонусы** при пополнении
- **Резервирование** баллов на время покупки
- **VIP скидка 20%** на все покупки

### ⚙️ **Автопокупка (VIP)**
- **Настраиваемые фильтры** по цене и тиражу
- **Категории подарков** для автовыбора
- **Дневные лимиты** покупок
- **Статистика** покупок

## ⚙️ **НАСТРОЙКА И ЗАПУСК**

### 1. **Подготовка окружения**
```bash
# Установка зависимостей
pip install -r requirements.txt

# Копирование конфигурации
cp env_example.txt .env
```

### 2. **Настройка .env файла**
```bash
# Основные настройки
BOT_TOKEN=your_bot_token
ADMIN_ID=your_telegram_id

# ЮКасса
YOOKASSA_SHOP_ID=your_shop_id
YOOKASSA_SECRET_KEY=your_secret_key

# TON кошельки
TON_WALLET_1_ADDRESS=your_ton_address_1
TON_WALLET_2_ADDRESS=your_ton_address_2

# Депозитные аккаунты (2 аккаунта для мониторинга и покупок)
DEPOSIT_ACCOUNT_1_API_ID=your_api_id_1
DEPOSIT_ACCOUNT_1_API_HASH=your_api_hash_1  
DEPOSIT_ACCOUNT_1_PHONE=+7999...

DEPOSIT_ACCOUNT_2_API_ID=your_api_id_2
DEPOSIT_ACCOUNT_2_API_HASH=your_api_hash_2
DEPOSIT_ACCOUNT_2_PHONE=+7999...
```

### 3. **Инициализация системы**
```bash
python init_new_system.py
```

### 4. **Тестирование**
```bash
python test_new_system.py
```

### 5. **Запуск бота**
```bash
python main_bot.py
```

## 💰 **ЭКОНОМИЧЕСКАЯ МОДЕЛЬ**

### 📋 **Подписки:**
- **Basic (699₽/месяц):** Мониторинг + уведомления
- **VIP (1299₽/месяц):** Все функции + автопокупка + скидки

### 💎 **Система баллов:**
- **1₽ = 1 балл** базовый курс
- **Бонусы при пополнении:**
  - 1000-5000₽ → +5% баллов
  - 5000-10000₽ → +10% баллов  
  - 10000₽+ → +15% баллов

### 💸 **Комиссии:**
- **15% комиссия** с покупки подарков
- **20% скидка VIP** на все покупки
- **Минимальное пополнение:** 100₽

# ⚠️ КРИТИЧЕСКИ ВАЖНЫЕ ПРОВЕРКИ - БЫСТРЫЙ СПИСОК

## 🚨 ПЕРЕД ЗАПУСКОМ - ОБЯЗАТЕЛЬНО!

### 1. FloodWait Статус (КРИТИЧНО!)
```bash
python debug_auth.py
```
**❌ НЕ ЗАПУСКАТЬ если видите FLOOD_WAIT_X**
**✅ Запускать ТОЛЬКО после истечения блокировки**

### 2. Файлы Сессий
```bash
ls -la *.session*
```
**Должен быть**: `bot_session.session` (28KB)

### 3. Конфигурация
```bash
cat config.py | head -10
```
**Проверить**: API_ID, API_HASH, BOT_TOKEN заполнены

### 4. База Данных
```bash
python -c "import sqlite3; print('OK' if sqlite3.connect('bot_database.db').execute('SELECT 1').fetchone() else 'ERROR')"
```
**Ожидаем**: "OK"

### 5. Зависимости
```bash
python -c "import pyrogram, tgcrypto; print('Все пакеты установлены')"
```
**Ожидаем**: "Все пакеты установлены"

## 🔧 БЫСТРЫЕ КОМАНДЫ ЗАПУСКА

### Полная Проверка Системы
```bash
python test_system_readiness.py
```
**Ожидаем**: 97%+ готовности

### Создание Бэкапа
```bash
mkdir backup_$(date +%Y%m%d_%H%M%S) && cp *.py *.session* *.db backup_*/
```

### Запуск с Логированием
```bash
mkdir -p logs && python start_bot.py 2>&1 | tee logs/startup.log
```

## 🚨 КРАСНЫЕ ФЛАГИ - НЕМЕДЛЕННО ОСТАНОВИТЬ

### В Логах НЕ Должно Быть:
- `FLOOD_WAIT_`
- `FloodWait`
- `ConnectionError`
- `sqlite3.OperationalError`
- `MemoryError`

### Команды Экстренной Остановки:
```bash
# Остановить бота
pkill -f start_bot.py

# Проверить что остановился
pgrep -f start_bot.py

# Посмотреть последние ошибки
tail -20 logs/startup.log
```

## ✅ ХОРОШИЕ СИГНАЛЫ

### В Логах Должно Быть:
- `Bot started successfully`
- `Database connected`
- `Pyrogram client initialized`
- `TgCrypto acceleration enabled`

### Тестовые Команды (после запуска):
```
/start    - должен ответить приветствием
/help     - должен показать помощь
/balance  - должен показать баланс
```

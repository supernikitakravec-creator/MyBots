# 🖥️ ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ СЕРВЕРА ДЛЯ TgGIFT BOT

## 📊 **МИНИМАЛЬНЫЕ ТРЕБОВАНИЯ**

### 💻 **Процессор (CPU)**
- **Минимум**: 2 vCPU / 2 ядра
- **Рекомендуется**: 4 vCPU / 4 ядра
- **Частота**: от 2.4 GHz
- **Архитектура**: x86_64 (AMD64)

### 🧠 **Оперативная память (RAM)**
- **Минимум**: 4 GB RAM
- **Рекомендуется**: 8 GB RAM
- **Оптимально**: 16 GB RAM

**Распределение памяти:**
```
PostgreSQL:     1-2 GB
Redis Cache:    512 MB - 1 GB
Redis Queue:    256 MB - 512 MB
Bot Workers:    1-2 GB (4 воркера по 256-512 MB)
Nginx:          64-128 MB
Система:        1-2 GB
Резерв:         1-2 GB
```

### 💾 **Дисковое пространство (Storage)**
- **Минимум**: 50 GB SSD
- **Рекомендуется**: 100 GB SSD
- **Тип**: SSD (обязательно для PostgreSQL)

**Распределение дискового пространства:**
```
Система:              20 GB
PostgreSQL данные:    10-20 GB
Логи:                 5-10 GB
Docker образы:        5-10 GB
Бэкапы:              10-20 GB
Резерв:              10-20 GB
```

### 🌐 **Сетевые требования**
- **Пропускная способность**: от 100 Mbps
- **Трафик**: ~10-50 GB/месяц (зависит от нагрузки)
- **Латентность**: < 50ms до Telegram серверов
- **IPv4**: Обязательно (статический IP предпочтительно)
- **IPv6**: Желательно

## 🛡️ **БЕЗОПАСНОСТЬ И ДОСТУП**

### 🔐 **SSH доступ**
- **Ключи**: RSA 4096 или Ed25519
- **Порт**: Изменить с 22 на нестандартный
- **Root**: Отключить прямой вход
- **Пароли**: Отключить аутентификацию по паролю

### 🔥 **Файрвол**
```bash
# Открытые порты
22 (SSH) - только с ваших IP
80 (HTTP) - для редиректа на HTTPS
443 (HTTPS) - основной трафик
```

### 📊 **Мониторинг**
```bash
# Внутренние порты (только localhost)
5432 (PostgreSQL)
6379 (Redis Cache)
6380 (Redis Queue)
8080 (Health Check)
8090 (Metrics)
3000 (Grafana)
9090 (Prometheus)
```

```bash
max_connections = 200
```

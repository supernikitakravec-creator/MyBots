### **💰 Управление подписками:**
```
/grant_sub <user_id> [дни]     # Выдать подписку
/revoke_sub <user_id>          # Отозвать подписку  
/check_subs                    # Список всех подписок
/cleanup_subs                  # Очистить истекшие
```

### **🎟️ Управление промокодами:**
```
/create_promo [кол-во] [дни]   # Создать промокоды (по умолчанию: 30 кодов на 30 дней)
/promo_stats                   # Статистика использования промокодов
/list_promo [active|used]      # Список промокодов (активные/использованные)
/delete_promo <код>            # Удалить конкретный промокод
```

### **🎛️ Системные настройки:**
```
/demo_mode on|off              # Демо-режим вкл/выкл
/admin_help                    # Справка по командам
/checkpay <payment_id>         # Статус платежа ЮКассы
```

### **📊 Мониторинг:**
- **Демо-режим ON:** Все функции доступны бесплатно
- **Демо-режим OFF:** Проверка подписки активна
- **Автоуведомления:** За 3 дня до истечения подписки

### **🎟️ Примеры работы с промокодами:**

**Создание промокодов (админ):**
```
/create_promo                  # 30 кодов на 30 дней
/create_promo 10               # 10 кодов на 30 дней
/create_promo 20 60            # 20 кодов на 60 дней
```

**Управление промокодами (админ):**
```
/promo_stats                   # Статистика: всего/активных/использованных
/list_promo active             # Список активных промокодов
/list_promo used               # Список использованных промокодов
/delete_promo FIT123ABC456     # Удалить конкретный промокод
```

**Использование промокодов (пользователи):**
- Нажать кнопку **"🎟️ Промокод"** в главном меню
- Ввести промокод формата `FIT123ABC456`
- Получить подписку на указанный период
- Команда `/promo КОД` также работает
